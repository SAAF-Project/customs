# Security policy

Please report weaknesses in Customs **privately**, not as a public issue:
email **info@saafproject.com** with "Customs security" in the subject.

Describe what you found and how to reproduce it, for example a hidden instruction
that Customs fails to catch, or a way to make it clear a contribution it should block.
Never include live keys, tokens or personal data in a report.

Customs is maintained by volunteers. We aim to acknowledge a report within a week.
